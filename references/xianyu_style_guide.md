# 咸鱼体商品介绍风格指南

## 一、核心风格特征

咸鱼体是闲鱼二手交易平台特有的商品描述风格，核心特征如下：

### 1. 口语化 & 接地气
- 像跟朋友面对面聊天，不做作
- 使用口头禅、语气词：啊、嘛、呢、呗、啦、哈
- 可以适当使用方言词汇增加亲切感

### 2. 卖货理由（必选其一）
每个商品介绍都需要一个"为什么卖"的理由，越真实越好：
- **升级换代**：换新了/升级了/买了更好的 → "换了最新款，这台就闲置了"
- **吃土回血**：最近花太多/吃土了 → "双十一剁手太狠了，回点血🤣"
- **搬家清仓**：搬家/换城市 → "搬家东西太多带不走，忍痛出"
- **用不上**：买回来没用几次 → "买来就用了两次，一直吃灰..."
- **分手/前任**：情感类理由（谨慎使用）→ "前任送的表，看着心烦，出了"
- **别人送的**：礼物用不上 → "朋友送的，我风格不太搭"
- **囤多了**：多买了一时用不完 → "囤了好几盒，根本用不完"
- **退坑**：不玩这个了 → "退坑出装备，全套打包"

### 3. 自嘲 & 幽默
- 适当自黑，增加真实感："手残党的我，买来就后悔了"
- 用轻松的玩笑化解商品的瑕疵或不足
- 不要太正经，但要真诚

### 4. 亲切称呼
根据商品类型和目标受众选择称呼：
- 通用：宝子们/家人们
- 女性向：姐妹们/集美们
- 男性向：兄弟们/老铁们
- 数码类：各位大佬/朋友们

### 5. Emoji 使用规则
- **必须有 emoji**，这是咸鱼体的标志性特征
- 标题/每段开头用对应 emoji 点缀
- Emoji 密度：每 2-3 行至少有一个
- 常用 emoji 分类：
  - 积极：✨🔥💯👍🎉💕🌟
  - 商品状态：📦🎁🔖💎👀
  - 情绪：😭🤣😅🥺😂💀🙏
  - 价格：💰💸🤑🏷️
  - 动作：👇🔗⚡📩💬
  - 交易：🤝✅❌🔪

### 6. 价格话术
- 默认不议价，价格已最低，无需在文案中额外标注
- "可小刀" = 可以稍微还价（仅用户明确要求时才使用）
- "不议价"/"一口价" = 不接受还价（默认态度）
- "半价不到" = 强调性价比
- "诚心要可聊" = 真心想买可以谈
- 默认包邮，无需在文案中标注"包邮"
- 仅用户明确说"不包邮""到付"时才在文案中说明邮费规则
- "懂的都懂" = 懂行的人知道这个价值

### 7. 商品状态描述
- 诚实但不沉重：轻微瑕疵用幽默带过
- 成色描述：几乎全新/9成新/正常使用痕迹/战斗成色
- 瑕疵描述举例：
  - "有个小划痕，不仔细看看不出来"
  - "边角有点磨损，但不影响使用"
  - "充电口有点松，但不影响充电，介意勿拍哈"

### 8. 常用结尾模板
- "手慢无！"
- "喜欢直接拍，看到就发"
- "拍之前可以问我，看到就回"
- "仅此一件，错过就没有啦"
- "诚心出，不墨迹"
- "懂的都懂，不解释了"
- "爽快的来，磨叽的别问"

### 9. 标签使用
商品介绍末尾必须添加标签，每行一个或以空格分隔：
- 必备标签：#闲置 #回血
- 品类标签：#数码 #美妆 #服饰 #家居 #图书 #母婴 #潮玩 #运动
- 品牌标签：根据实际品牌添加
- 特征标签：#正品 #限量 #绝版 #全新 #99新

### 10. 买前须知（必选板块）
标签之后必须添加"买前须知"板块，用于过滤交易风险和保护卖家权益。
此板块不参与咸鱼体风格化，保持正式清晰。

**格式：**
- 标签下方空一行，加分隔线 `---`
- 标题：`⚠️ 买前须知`
- 条款用有序列表，简洁直接

**默认条款：**
```
---
⚠️ 买前须知：
1. 仓库接单后不改单不撤单，48小时内发货。没货会退款。不接受拒收等操作，发货后由于买家自身原因不要了，需补偿快递费。
2. 支持7天无理由，无运费险。若发错货请于签收内24小时联系我处理，超时不售后。
3. 偏远地区需加邮费（西藏、新疆不发）
4. 其他产品可私我，带图和品牌来询价。
5. 快递随机，不指定快递
```

**自定义条款：** 如用户指定了不同的条款内容，优先使用用户版本。

## 三、质量检查清单

生成的咸鱼体介绍需满足以下标准：
1. ✅ 有卖货理由
2. ✅ 有 emoji 点缀（至少 3 处）
3. ✅ 有亲切称呼（姐妹/兄弟/宝子/家人）
4. ✅ 语气口语化、自然不做作
5. ✅ 商品信息完整（价格/成色/规格等）
6. ✅ 末尾有标签
7. ✅ 有价格话术或交易方式说明
8. ✅ 整体有"人味儿"，不像AI写的
